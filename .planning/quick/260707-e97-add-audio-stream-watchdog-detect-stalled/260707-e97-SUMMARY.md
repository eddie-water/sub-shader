# Quick Task 260707-e97: Audio Stream Watchdog Summary

**Wall-clock stall watchdog in AudioStream.next_chunk() turns the WSL2 ALSA-underrun hard-hang into a graceful AudioStreamStalledError shutdown**

## Performance

- **Duration:** ~5 min
- **Completed:** 2026-07-07
- **Tasks:** 3/3
- **Files modified:** 4

## Accomplishments

- `AudioStreamStalledError(SubShaderException)` with `log_level = "error"` — caught by main() via the existing GRACEFUL_EXCEPTIONS tuple, so cleanup runs and the window can close.
- `AudioPlayer.is_active()` — cheap corroborating signal (`_stream is not None and _stream.active`) folded into the error message, never gating the raise.
- `next_chunk()` watchdog: `time.monotonic()` bookkeeping in the existing wait loop. If the playback clock stays frozen below the chunk boundary for `self._stall_timeout_s` (default `STREAM_STALL_TIMEOUT_S = 2.0`), it raises with a message referencing the ALSA underrun / WSL2 audio bridge and suggesting a restart. Clock movement resets the deadline; the advance/frame-skip/loop-wrap paths (D-06/D-08/D-09/D-11) are unchanged. No new threads or daemons.
- `tests/test_audio_watchdog.py`: frozen fake clock raises within a 0.05s overridden timeout; live clock at the boundary returns the reader sentinel with the expected hop-aligned seek. Both pass in 0.13s with `--noconftest`.

## Deviations from Plan

**1. [Minor] Skipped the redundant watchdog reset in the advance branch**
- **Found during:** Task 2
- **Issue:** Plan asked to reset `last_pos`/`stall_deadline` before returning "so a subsequent call starts fresh" — but both are function-local variables seeded at the top of every `next_chunk()` call, so the pre-return assignments would be dead code.
- **Fix:** Relied on the entry-point seeding; subsequent calls already start with a fresh deadline. Matches project style (no dead code / comment litter).
- **Verification:** Live-clock test returns without raising; stall test raises within the tiny timeout.

**Total deviations:** 1 minor (dead-code avoidance)
**Impact on plan:** None — behavior identical to plan intent.
