<objective>
Add a simple, effective audio stream watchdog. When the sounddevice OutputStream
stalls after an ALSA underrun (WSL2 PulseAudio bridge), the callback stops firing,
AudioPlayer._current_frame freezes, and the main thread parks forever in
next_chunk()'s `time.sleep(0.001)` retry loop — the app hard-hangs and the window
cannot even close.

The fix: track wall-clock time inside the existing wait loop. If the playback
position has not advanced for STREAM_STALL_TIMEOUT_S seconds while waiting on a
chunk boundary, raise a graceful AudioStreamStalledError instead of looping forever.

Purpose: Turn an unrecoverable hard-hang into a clean, reported shutdown.
Output: New domain exception, an AudioPlayer.is_active() corroborating signal,
watchdog bookkeeping in next_chunk(), and a fast unit test.

Scope guardrails (per request):
- No new threads, no polling daemons — just wall-clock bookkeeping in the loop.
- Clock-not-advancing timeout is the PRIMARY trigger; stream.active is only a
  corroborating detail folded into the error message.
</objective>

<task type="auto">
  <name>Task 2: Add wall-clock watchdog to next_chunk()</name>
  <files>src/subshader/audio/audio_stream.py</files>
  <action>
Add module-level constant `STREAM_STALL_TIMEOUT_S = 2.0` (seconds of wall time the
playback clock may stay frozen on a boundary before the stream is treated as stalled).
In AudioStream.__init__, set `self._stall_timeout_s = STREAM_STALL_TIMEOUT_S` so tests
can override the instance attribute without changing the constructor signature.
Import AudioStreamStalledError from subshader.exceptions.

Rework the next_chunk() wait loop to add wall-clock bookkeeping using time.monotonic():
- Before the loop, seed `last_pos = self._player.get_playback_sample()` and
  `stall_deadline = time.monotonic() + self._stall_timeout_s`.
- Inside the loop, in the `playback_pos < next_boundary` branch:
    * If `playback_pos != last_pos`: the clock is alive — update `last_pos = playback_pos`
      and reset `stall_deadline = time.monotonic() + self._stall_timeout_s`.
    * Else (clock frozen) and `time.monotonic() >= stall_deadline`: raise
      AudioStreamStalledError. Fold the corroborating signal into the message: call
      `self._player.is_active()` and include it (e.g. "audio clock frozen at sample
      {playback_pos} for {timeout}s (stream active={is_active}); likely an ALSA
      underrun on the WSL2 audio bridge — restart the app / audio device to recover").
      Log at error via the exception's log_level path (raising is enough; main() reports it).
    * Keep the existing `time.sleep(0.001); continue`.
- In the advance branch (clock reached/passed the boundary), reset the watchdog:
  `last_pos = playback_pos` and `stall_deadline = time.monotonic() + self._stall_timeout_s`
  before returning, so a subsequent call starts fresh. The loop-wrap reset and frame-skip
  seek behavior (D-06/D-08/D-09/D-11) must stay exactly as they are.

Primary trigger is the frozen-clock timeout; is_active() is diagnostic only — do NOT
gate the raise on is_active() being False (the fake test player must be able to trigger
the raise purely via the frozen clock).
