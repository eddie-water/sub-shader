<objective>
Introduce a panel-unit OOP composition layer for dsplot. Panels declare a class-level `default_units` tuple (W, H); `Figure.compose(rows=[[panel, ...], ...])` auto-derives figsize, gridspec width-units, and per-panel colspan. Adds new `TimeSeriesPanel`, `HeatmapPanel`, and `CompositePanel` classes (one level of nesting only). Purely additive: existing `Figure(n_rows=..., n_cols=..., width_ratios=...)` constructor and all existing figures (`components_recombine`, `style_skeleton`) continue to work unchanged.

Purpose: Replace ad-hoc per-figure width-ratio bookkeeping with a "lego" composition system where each panel type carries its natural aspect ratio.
Output: New panel classes, new `Figure.compose` classmethod, new `DEFAULT_PANEL_UNIT_INCHES` style constant, new `lego_demo.py` figure module + rendered PNG.
