<task type="auto">
  <name>Task 1: Fix duration_s overlap formula in generate_comparison_grid</name>
  <files>research/benchmark.py</files>
  <action>
    Fix the duration_s calculation on line 806 of research/benchmark.py inside generate_comparison_grid().

    **Current (wrong):**
    ```python
    duration_s = frames_processed * chunk_size / sr
    ```
    This ignores overlap_factor. With overlap_factor=0.5, each frame advances by hop_size = chunk_size * (1 - overlap_factor), NOT by chunk_size. The current formula nearly doubles the true duration, causing the reference waveform/inst-freq trace to extend past where spectrograms have energy.

    **Replace with:**
    ```python
    hop_size = int(chunk_size * (1 - overlap_factor))
    duration_s = ((frames_processed - 1) * hop_size + chunk_size) / sr
    ```

    This correctly computes: first frame covers [0, chunk_size], each subsequent frame advances by hop_size. Total samples = (N-1)*hop + chunk_size.

    Note: `overlap_factor` is already in scope (line 676). The variable name `hop_size` does not conflict with anything in this function (the only existing `hop` variable is inside the `else` branch of the file-based signal path at line 727, scoped separately).

    Do NOT change anything else in the function. This is a surgical one-line fix.
  </action>
