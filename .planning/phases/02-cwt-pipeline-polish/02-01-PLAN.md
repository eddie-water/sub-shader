<objective>
Fix the CWT frequency-band brightness bias at its root cause and prove the fix with tests.

Purpose: Low-frequency bands appear disproportionately brighter than high-frequency bands because wavelet kernel L1 norm scales as 1/f. This plan normalizes kernels to unit L1 area at construction time, making CWT response constant across frequencies. Tests are written first (TDD) to define correct behavior before applying the fix.

Output: Normalized wavelet kernels, passing test suite, clean config (dead code removed).
</objective>
