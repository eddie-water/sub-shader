```python
# research/dsplot/plottables/spotlight.py
class Spotlight(Plottable):
    """Highlight overlay. mode controls shape:
      - "rectangle": axvspan(x_range) or axhspan(y_range), supports both
      - "scatter":   single emphasized point at (x, y) with size + glow
      - "glow":      alpha-graded circle at (x, y), useful for animation focus
    """
    def __init__(self, *,
                 mode: str = "rectangle",
                 x_range: tuple[float, float] | None = None,
                 y_range: tuple[float, float] | None = None,
                 xy: tuple[float, float] | None = None,
                 radius: float = 0.05,
                 color: str | None = None,
                 alpha: float = 0.35,
                 linewidth: float = 1.5,
                 linestyle: str = "--",
                 zorder: int = 6): ...
```

<risks>
- **TimeSeries default color (NEUTRAL_COLOR vs PRIMARY_COLOR):** Decision: NEUTRAL_COLOR. The dsplot palette reserves PRIMARY for "vector a identity" and SECONDARY for "vector b identity". A bare TimeSeries on a panel is generic display, not identity-bearing. If a consumer wants to brand it, they pass color explicitly. Document in TimeSeries class docstring.
- **Heatmap vmax precedence:** Explicit vmax > vmax_percentile kwarg > style.DEFAULT_HEATMAP_VMAX_PERCENTILE constant. This is the standard pattern but easy to invert by accident. Test 7 pins it.
- **Spotlight rectangle accepting both x_range and y_range:** Some consumers will want both at once (a true 2D rectangle). Decision: support both; render two axspans. If a consumer wants a single rectangular outline patch instead of two crossed spans, they can compose that later (or open a follow-up to add a `mode="patch"` for full Rectangle patches). Not a Phase 9 concern.
- **D-05 lazy-lookup uniformity:** Tests 8 (heatmap) and 10 (dropline) pin the lazy-lookup contract for two Plottables. Same pattern applies to TimeSeries, Spotlight — verify in code review that each `draw()` method resolves None style knobs against `dsplot.style.DEFAULT_*` INSIDE the method, not at __init__.
</risks>
