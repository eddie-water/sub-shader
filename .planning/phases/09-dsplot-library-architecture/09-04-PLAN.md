```python
# research/dsplot/panels/dynamic_panel.py
from __future__ import annotations
from typing import Callable
from ..plottables.base import Plottable
from .base import Panel

# A frame is a list of Plottables to draw on this panel's axes for that frame.
Frame = list[Plottable]

class DynamicPanel(Panel):
    """Multi-frame panel rendered as a matplotlib FuncAnimation loop.

    Frames are pre-computed (frames: list[Frame]) OR generated lazily
    (frame_fn: Callable[[int], Frame]).

    Loops with auto-reset (FuncAnimation repeat=True). Holds a reference to
    the FuncAnimation object on self so the animation isn't garbage-collected
    when render() returns.
    """
    def __init__(self, *,
                 frames: list[Frame] | None = None,
                 frame_fn: Callable[[int], Frame] | None = None,
                 num_frames: int | None = None,    # required if frame_fn is set
                 interval_ms: int = 250,
                 repeat: bool = True,
                 # static base layers drawn once, beneath frame-varying plottables:
                 base_plottables: list[Plottable] | None = None,
                 # standard StaticPanel kwargs forwarded:
                 title: str | None = None,
                 subtitle: str | None = None,
                 lim: float | None = None,
                 axis_style: str = "line",
                 axis_labels: bool = False,
                 show_border: bool = True): ...

    def save_gif(self, path: str, *, fps: int = 4, dpi: int | None = None) -> str:
        """Save the animation as a GIF (uses PillowWriter)."""
```

```python
# research/dsplot/panels/interactive_panel.py
class InteractivePanel(Panel):
    """Multi-frame panel driven by ipywidgets controls.

    Falls back to a static render of frame 0 (with a one-line warning) if
    ipywidgets isn't importable — keeps the library usable outside notebooks.

    Controls (always shown if ipywidgets available): Prev / Next buttons.
    Optional: slider (slider=True), checkbox bound to a callback for show/hide
    overlays (checkbox=("label", callback)).
    """
    def __init__(self, *,
                 frames: list[Frame],
                 base_plottables: list[Plottable] | None = None,
                 slider: bool = False,
                 checkbox: tuple[str, Callable[[bool], None]] | None = None,
                 # standard StaticPanel kwargs forwarded:
                 title: str | None = None,
                 subtitle: str | None = None,
                 lim: float | None = None,
                 axis_style: str = "line",
                 axis_labels: bool = False,
                 show_border: bool = True): ...
```

<risks>
- **FuncAnimation GC trap:** Forgetting to hold `self._anim` reference is the single most common matplotlib animation bug. The implementation comment and Test 4 are the guardrails — if Test 4 passes today but a future refactor strips the `self._anim` assignment, the animation will silently render only frame 0. Treat that line as load-bearing.
- **ipywidgets Jupyter extension activation (USER SETUP):** A bare `pip install ipywidgets` does NOT always activate the classic Jupyter notebook extension. JupyterLab generally Just Works; classic Jupyter notebook may need `jupyter nbextension enable --py widgetsnbextension`. This is captured in user_setup frontmatter and verified in checkpoint task 3. If the user reports controls don't appear, this is the first thing to check.
- **Mixed-type composition unknowns:** Matplotlib FuncAnimation in a Figure containing a non-animated subplot generally works (the animation function only touches its own axes), but ipywidgets controls embedded in a Figure with multiple panels is a more rarely-tested path. The 2-hour timebox per LOCKED non-goal #6 is the safety valve. The checkpoint explicitly authorizes the fallback decision at the developer's discretion.
- **per-frame artist cleanup vs. `ax.cla()`:** `ax.cla()` would also nuke background, spines, and base_plottables, forcing a re-render each frame and dropping FPS. The tracked-artist removal pattern preserves them. Test 9 specifically catches `ax.cla()` regressions by asserting base layers survive multiple `_animate` calls.
</risks>
