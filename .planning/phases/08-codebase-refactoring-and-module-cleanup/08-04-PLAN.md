    Create `src/subshader/audio/audio_stream.py`:

    ```python
    class AudioStream:
        """Facade wrapping audio file I/O and playback.

        Takes a PipelineConfig, discovers sample_rate and total_samples
        from the audio file, and writes them back into config so downstream
        modules (CWT, Renderer) see the correct values.
        """

        def __init__(self, config):
            self.config = config
            self._reader = AudioReader(config)    # discovers sample_rate, writes to config
            self._player = AudioPlayer(config)    # reads config.file_path, config.sample_rate

        def start(self):
            """Start audio playback."""
            self._player.start()

        def get_chunk(self):
            """Get next audio chunk (non-blocking). Returns None if no new data."""
            return self._reader.get_chunk()

        def next_chunk(self):
            """Get next chunk, blocking until audio clock advances.

            Implementation: Check if audio playback position has advanced
            past current reader position. If yes, seek reader and return chunk.
            If no, yield briefly (time.sleep(0.001)) and retry.
            This matches the current __main__.py sync loop behavior.
            """
            # Look at current __main__.py loop() method for the sync logic:
            # It compares audio_player.get_playback_sample() with audio_input.file_pos
            # and seeks/skips accordingly. Encapsulate that logic here.
            ...

        def get_playback_sample(self) -> int:
            """Current playback position in samples."""
            return self._player.get_playback_sample()

        def has_looped(self) -> bool:
            """Whether playback has looped back to start."""
            return self._player.has_looped()

        def cleanup(self):
            """Stop playback and close file handles."""
            self._player.stop()
            self._reader.cleanup()  # if reader has cleanup; otherwise close file
    ```

    The `next_chunk()` method should encapsulate the audio-clock sync logic currently in `__main__.py`'s `loop()` method. Read __main__.py to understand:
    - It compares `audio_player.get_playback_sample()` with `audio_input.file_pos`
    - If render falls behind, it skips frames (seeks forward)
    - If audio hasn't advanced, it sleeps 1ms
    - Encapsulate this into `next_chunk()` so pipeline.py can just call `audio.next_chunk()` in a clean loop

    Apply `@timed` decorator on `get_chunk()` and `next_chunk()` per D-21.
