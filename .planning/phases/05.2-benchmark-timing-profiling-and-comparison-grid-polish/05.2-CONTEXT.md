<decisions>
## Implementation Decisions

### --timing Sub-Stage Profiling
- **D-01:** Add `cwt_timed()` method to the Wavelet base class in `wavelet.py`. Returns `(result, timings_dict)` where timings_dict has keys for each pipeline stage: `raw_cwt`, `normalize`, `magnitude`, `edge_trim`, `hop_center`, `downsample`.
- **D-02:** `cwt_timed()` calls the same methods as `cwt()` but wraps each with `time_call()`. Lives next to `cwt()` in wavelet.py so pipeline drift is visible in the same file.
- **D-03:** `TimedSubShader.run()` calls `wavelet.cwt_timed()` instead of `wavelet.cwt()` and prints per-stage breakdown in the timing table.
- **D-04:** Add render timing — time `CircularFrameBuffer.push_frame()` or equivalent buffer operation in the timing loop.

### --comparison NumPy Timing
- **D-05:** Add NumPyWavelet as a 4th timed method in the `--comparison` timing table, alongside STFT, PyWavelet, and CuPy.
- **D-06:** Labels in comparison table: `SubShader (CPU)` for NumPyWavelet, `SubShader (GPU)` for CuPyWavelet. PyWavelet stays as `PyWavelet`.
- **D-07:** No new figure row — NumPy timing is printed in the comparison table only.
- **D-08:** `--stub-pywt` skips PyWavelet as before; NumPy and CuPy still run and are timed.

### Grid Visual Polish (Commit Existing Work)
- **D-09:** Commit all grid visual changes already implemented in this session as part of this phase:
  - PyWavelet `1/sqrt(scale)` normalization in `PyWavelet.normalize_by_scale()`
  - Comparison grid label column (gridspec layout, auto-width from longest label)
  - `GRID_BG_COLOR = "#1A1A1A"` constant replacing hardcoded `#1a1a2e`
  - DAW row freq y-axis ticks matching spectrogram scale
  - "Freq (Hz)" label on STFT row only (middle of grid)
  - `test_normalization_comparability` test verifying PyWavelet/SubShader energy parity
- **D-10:** No further grid visual changes in this phase. Axis label styling, DPI selection, decorator utilities are out of scope.

### Claude's Discretion
- Exact timing table formatting for sub-stage breakdown
- Whether to include a total row summing sub-stages
- How to handle render timing when no GPU/display available (skip gracefully)

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `time_call()` in `research/utilities/__init__.py` — wraps any callable with perf_counter timing, returns `(result, ms)`
- `TimingAccumulator` — pre-allocated numpy array per method, supports `trim()` and indexed access
- `print_results_header/row/loop_summary` — formatted timing table output

### Established Patterns
- `cwt()` pipeline in Wavelet base class: `class_specific_cwt → normalize_by_scale → compute_mag → discard_unreliable_coefs → extract_hop_center → downsample`
- `--comparison` flag already times STFT, PyWavelet, SubShader per-frame in `generate_comparison_grid()`
- All timing uses `time.perf_counter()` via `time_call()` wrapper

### Integration Points
- `TimedSubShader` already instantiates CuWavelet or NumPyWavelet based on GPU availability
- `generate_comparison_grid()` already creates both PyWavelet and NumPyWavelet instances

</code_context>
