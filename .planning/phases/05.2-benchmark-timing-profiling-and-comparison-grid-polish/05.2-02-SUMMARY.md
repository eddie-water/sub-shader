## What Was Built

**Task 1: 4-method comparison timing in generate_comparison_grid()**

Modified `generate_comparison_grid()` in `research/figures.py` with four targeted changes:

1. **GPU detection at function entry** — `GPU_COMP_AVAILABLE = gpu_available()` added immediately after the `wav_export` import. Evaluated once per function call, not per frame.

2. **Accumulator setup extended** — replaced bare `"SubShader"` key with `"SubShader (CPU)"`, and conditionally appends `"SubShader (GPU)"` when `GPU_COMP_AVAILABLE` is True. When `--stub-pywt` is passed, `"PyWavelet"` is excluded but both SubShader variants are still present.

3. **CuWavelet conditional instantiation** — after `NumPyWavelet` init, `cpwt = None` is set unconditionally (safe default in frame loop), then overwritten with a `CuWavelet` instance when `GPU_COMP_AVAILABLE and comparison`. Import is deferred inside the function to avoid unconditional GPU dependency at module load.

4. **Per-frame loop updated** — `acc["SubShader"]` renamed to `acc["SubShader (CPU)"]` for NumPy timing; GPU timing added as `_, acc["SubShader (GPU)"][acc.current_idx] = time_call(cpwt.cwt, chunk)` guarded by `if cpwt is not None and comparison`. GPU result is discarded — no new figure rows added.

The existing printing section (`for method in acc.methods`) already iterates all methods automatically — no change needed there.
