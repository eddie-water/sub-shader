## What Was Built

**Task 1: cwt_timed() on Wavelet base class**

Added `import time` at module top and a new concrete method `cwt_timed()` on the `Wavelet` ABC, placed immediately after `cwt()`. The method mirrors the exact 6-stage pipeline of `cwt()` but wraps each stage with `time.perf_counter()`:

- `raw_cwt` — `class_specific_cwt()`
- `normalize` — `normalize_by_scale()`
- `magnitude` — `compute_mag()`
- `edge_trim` — `discard_unreliable_coefs()`
- `hop_center` — `extract_hop_center()`
- `downsample` — `downsample()`

Returns `(downsampled_coefs, timings_dict)` where `timings_dict` maps each stage name to elapsed milliseconds as a float.

Two new tests added to `test_wavelet.py`:
- `test_cwt_timed_returns_six_stages` — verifies the dict has exactly the 6 expected keys, all positive floats
- `test_cwt_timed_output_matches_cwt` — verifies output is numerically identical to `cwt()` (rtol=1e-10)

**Task 2: TimedSubShader with 8-row breakdown**

Updated `research/timing.py`:
- Added `from subshader.viz.plotter import CircularFrameBuffer` and `ColorNormalizationConfig` imports
- Replaced 2-method `TimingAccumulator(["get_chunk()", "cwt()"])` with 8-method accumulator
- `CircularFrameBuffer` instantiated in `run()` after wavelet init using `wavelet.get_output_shape()`
- Loop now calls `wavelet.cwt_timed()` and distributes 6 stage timings into the accumulator
- `push_frame()` timed via `time_call(buf.push_frame, result)`
- Results section prints: `get_chunk()`, separator, 6 indented sub-stage rows, `cwt() total` (summed), separator, `push_frame()`, then loop summary
