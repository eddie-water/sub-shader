## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Over-engineered pedagogical figure | Figure 2 was first built as a 2-panel projection-onto-each-other figure with the **perpendicular complement** drawn and **two reconstruction paths** overlaid as a parallelogram. The extras buried the actual claim (a·b = b·a). User feedback: "I don't get what figure 2 is trying to show me." | advisory | Before adding visual elements to a pedagogical figure, name the single bullet the figure must read. Anything that doesn't directly read that bullet is noise. If a bullet earlier in the section already carries an idea (e.g., "components recombine in any order"), the figure should not re-illustrate it. |
| Numerical coincidence in pedagogical figure | The canonical numbers a=(1.0, 0.5), b=(0.6, 0.8) produce a·b = 1.0 AND \|b\|² = 1.0, which makes the projection of `a` onto `b` land exactly at b's tip. The "shadow" becomes visually indistinguishable from `b`, killing the symmetry pedagogy in that panel. | advisory | When picking canonical numbers for a projection figure, sanity-check the scalar (a·b)/(b·b) is not 1.0 (or anywhere near it). The reader needs to see the shadow as DIFFERENT from the reference vector. |
