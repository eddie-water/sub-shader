## Test Infrastructure (emerged from Scope discussion)

User clarified that unit_tests.py should be split into colocated test files alongside source modules in src/subshader/. Flat colocated pattern (test_wavelet.py next to wavelet.py) rather than test subdirectories. Top-level pytest discovers all tests.

User asked: "is this how professionals do it?" — Both patterns are common. Flat colocated is most common in Python (Django, FastAPI, most OSS). Test subdirectories used by numpy/scipy at scale. Flat colocated chosen as pragmatic for this project size.
