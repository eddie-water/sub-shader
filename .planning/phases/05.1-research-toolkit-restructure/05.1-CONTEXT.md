# Phase 5.1: Research Toolkit Restructure - Context

**Gathered:** 2026-03-24
**Status:** Ready for planning

<domain>
## Phase Boundary

Break the monolithic `research/benchmark.py` (1191 lines, 13+ CLI flags) into a modular research toolkit. Redistribute misplaced files so everything has a home. Split the monolithic unit test file into colocated test files alongside source modules.

**Deliverables:**
- `research/benchmark.py` reduced to thin CLI dispatcher (~60 lines)
- New modules: `research/figures.py`, `research/timing.py`, `research/wav_export.py`
- `research/utilities/` preserved as shared research infrastructure
- `research/utilities/unit_tests.py` split into colocated `test_*.py` files in `src/subshader/`
- `research/overlap_diagnostic.py` folded into relevant colocated test file
- `research/font_showcase_20.py` relocated near style/config
- All existing `benchmark.py --flag` commands continue to work

</domain>

<decisions>
## Implementation Decisions

### Module Split Strategy
- **D-01:** Split benchmark.py by concern into three modules: `figures.py` (ReadmeFigures + generate_comparison_grid + generate_timing_bar_chart, ~800 lines), `timing.py` (TimedSubShader + run_default, ~200 lines), `wav_export.py` (export_signal_to_wav + bouncing chirp generation)
- **D-02:** `research/utilities/` stays as-is — shared research infrastructure (dsp_helpers, plotting, printing, timing, constants) used by all research modules

### CLI Entry Point
- **D-03:** `benchmark.py` becomes a thin dispatcher (~60 lines) — keeps all existing argparse flags, imports from new modules, dispatches to them. All existing CLI commands (`python research/benchmark.py --comparison-grid`, etc.) continue to work unchanged.

### Test Infrastructure
- **D-04:** `research/utilities/unit_tests.py` (24KB, 10 test categories) split into colocated test files alongside source modules — e.g., `src/subshader/dsp/test_wavelet.py`, `src/subshader/dsp/test_wavelet_kernel.py`
- **D-05:** Flat colocated pattern (test files next to source files), not test subdirectories — pragmatic for this project's size, pytest discovers with zero config
- **D-06:** `research/overlap_diagnostic.py` test logic folded into the relevant colocated test file (audio overlap tests)
- **D-07:** Top-level `pytest src/` discovers and runs all colocated tests

### File Relocation
- **D-08:** `research/font_showcase_20.py` moved near style/config (exact location: Claude's discretion)
- **D-09:** `research/pipeline_timing_profile.py` (26KB) stays as standalone research script — self-contained, not part of the toolkit restructure

### Migration Approach
- **D-10:** All-at-once refactor — no transitional compatibility shims. Clean break in two plans: Plan 1 splits benchmark.py + updates CLI dispatcher. Plan 2 redistributes utilities/unit_tests.py into colocated tests + relocates standalone files.

### Claude's Discretion
- Exact import structure and module-level `__all__` exports
- How to partition unit_tests.py test categories across colocated files
- Exact destination for font_showcase_20.py
- Whether to add `__init__.py` to test directories or rely on pytest discovery
- Internal helper organization within new modules

</decisions>
